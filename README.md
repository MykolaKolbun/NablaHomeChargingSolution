# Nabla Home Charging Solution

Home EV charger management: pair your wallbox, start/stop charging, watch live power,
review history. No payments.

| Folder | What |
|---|---|
| `EVOCPP/` | OCPP 1.6J / 2.x gateway (home version) |
| `HomeApi/` | .NET 10 backend |
| `HomeApi.Tests/` | Backend tests |
| `HomeApp/` | Mobile app (Expo) |
| `deploy/` | Docker Compose stack |
| `docs/` | Architecture & decisions |

See [docs/architecture.md](docs/architecture.md).
